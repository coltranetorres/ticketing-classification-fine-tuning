# Accuracy improvement plan (tuned Gemma-3-1B, out-of-distribution)

Context: tuned Gemma-3-1B scores 99.3% on Bitext test but 83.0% on the hand-written holdout v1 (Gemini 98.1-98.5%). Goal: raise out-of-distribution accuracy honestly.

## Rules
- Holdout v1 (`data/holdout/synthetic_holdout.jsonl`) is now a DEV set (its errors were inspected). Never put its text into generator prompts or training data.
- Holdout v2 (`data/holdout/synthetic_holdout_v2.jsonl`) is written and frozen BEFORE any new training; scored only for final candidates, once each, and not used for selection.
- Training augmentation is generated by Gemini via OpenRouter from label names + definitions + style instructions only (no holdout text), so holdout authorship style cannot leak into training.
- Model selection uses Bitext val200 + holdout v1 (dev). Report v2, Bitext test, v1.

## Steps
1. Write + freeze holdout v2 (270 rows, 10/intent, vaguer/indirect style). Check zero exact overlap with Bitext and v1.
2. Constrained label scoring in `h5.gemma` (`predict_scored`): pick the label with highest sequence log-likelihood among the 27, no unparseable. Evaluate on existing tuned adapter (dev v1 + test).
3. Augmentation: `scripts/generate_augmentation.py` -> `data/aug/augmented.jsonl` (~100/intent, varied styles, dedup, drop exact matches to any holdout/Bitext test text). Retrain LoRA on 1,000 Bitext + augmentation; choose LR/checkpoint on val200 + dev v1.
4. Final comparison on v2, Bitext test, v1 vs Gemini (names + definitions) -> `results/report_v2.md`.
5. Optional: confidence router (accuracy vs coverage), larger base model.
